## Features

- Light and dark mode
- Custom accent colour picker and colour palettes that work on every page
- Command palette (`Ctrl + K`)
- Live SEO X-Ray that audits the page's own HTML
- Mini JavaScript quiz and reflex game
- Responsive, accessible, keyboard friendly

## SEO

Title and meta tags, canonical URLs, Open Graph and Twitter cards, JSON-LD structured data, sitemap, robots.txt, RSS feed and a custom 404 page.
